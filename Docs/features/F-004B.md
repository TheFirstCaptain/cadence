# Feature F-004B: Goal Editor

## Objective

Add focused creation and editing of Goals with clear name and frequency validation for the selected weekly plan.

## User value

The user can quickly shape a realistic week and adapt it when life changes without rewriting prior History.

## Non-goals

- Selecting individual weekdays or allowing multiple completions per day.
- Reordering or removing Goals.
- Prorating a midweek target.
- Adding reminders, quantities, durations, or units.

## Acceptance notes

- Add and edit use a focused sheet with Cancel and Add or Save actions.
- The editor contains a Goal name and Daily, Weekly, or Custom frequency controls.
- Custom defaults to 2 and permits only 2 through 6 days per week.
- Goal names are trimmed, limited to 60 characters, and compared case-insensitively within the selected plan.
- A character count appears near the limit.
- Blank, over-length, invalid-frequency, and normalized-duplicate values cannot be saved and receive concise, nonjudgmental guidance.
- Cancel dismisses without persistence.
- New Goals appear at the bottom.
- Active-week rename and frequency changes apply immediately without prorating; existing checkoffs continue to count.
- Failed saves leave persisted and presented state coherent and allow retry.

## Workflow

- Tier: 3.
- Rationale: Editing mutates persisted weekly snapshots, affects active-week My Day behavior, and must preserve checkoffs and historical integrity.
