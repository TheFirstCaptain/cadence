# Feature F-001: Agentic Coding Harness

## Objective

Establish a lightweight, durable development contract for human and AI contributors before product implementation begins.

## User value

The harness protects Cadence's calm product philosophy, reduces scope drift, and applies proportionate review to privacy, persistence, time, accessibility, and data-loss risks.

## Non-goals

- Creating an Xcode project or application code.
- Selecting platform targets, persistence, signing, or third-party tools.
- Adding executable build or CI enforcement before native tooling exists.

## Acceptance notes

- Repository instructions point contributors to current source-of-truth documents.
- Work is classified as feature, bug, or engineering maintenance.
- Risk tiers define proportionate planning, review, and validation.
- Feature, bug, engineering, and decision templates exist.
- Product-specific acceptance, privacy, accessibility, date, and migration risks are represented.

## Clarification notes

The user requested an agentic coding harness informed by the local TabletopFog repository. The selected approach retains its durable documentation, classification, review, and shared-quality-contract principles while deferring Node-specific enforcement and reducing ceremony for low-risk work.
