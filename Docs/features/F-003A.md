# Feature F-003A: My Day Presentation Foundation

## Objective

Replace the My Day placeholder with a repository-backed screen foundation that presents Goals before iIndulged, groups planned Goals correctly, and handles loading, empty, ready, and recoverable failure states.

## User value

The user opens directly into a calm, understandable view of today, with daily intentions separated from flexible weekly intentions and an empty Goals invitation that does not displace the iIndulged section below it.

## Non-goals

- Mutating Goal checkoffs.
- Recording or removing iIndulged occurrences.
- Creating or editing Goals.
- Adding custom indulgence categories.
- Implementing History summaries.

## Acceptance notes

- My Day remains the default tab and shows Goals before iIndulged.
- Goal presentation is split into Today for Daily Goals and This Week for Weekly and Custom Goals.
- Goal rows preserve the weekly plan's manual order within each group.
- Weekly Goals show completed-of-1 progress; Custom Goals show completed-of-target progress.
- Completed Goals remain visible.
- An empty plan shows a calm invitation linking to My Goals without replacing or hiding the iIndulged section scaffold; F-003C makes its counters interactive.
- This slice adds the smallest focused daily-tracking read contract needed to return current-day activity plus current-week Goal checkoffs for Weekly and Custom progress. It does not couple presentation code to `HistoryRepository` or SwiftData.
- Screen state is produced by a MainActor-isolated presentation model using the focused repository contract and injected clock, calendar, and time-zone dependencies.
- Visible state refreshes when the scene returns to the foreground and when the captured local day or Monday-through-Sunday week changes.
- Loading and recoverable failure states use concise, nonjudgmental language and never expose persistence details.

## Clarification notes

This slice extracts presentation and read-state behavior from the approved F-003 contract. It does not change Goal frequency semantics or the Goals-before-iIndulged layout.
