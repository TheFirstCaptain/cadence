# Feature F-004A: Weekly Plan Lifecycle

## Objective

Establish the My Goals foundation that selects the correct Monday-through-Sunday plan, supports Sunday Planning for the upcoming week, and automatically carries Goals forward when planning is skipped.

## User value

The user always has a clear, flexible weekly plan without needing to recreate it each Monday.

## Non-goals

- Creating or editing individual Goals.
- Reordering or removing Goals.
- Adding reminders, notifications, or History presentation.
- Changing the approved Monday-through-Sunday calendar contract.

## Acceptance notes

- Monday through Saturday, My Goals presents the active week.
- On Sunday, My Goals presents the upcoming Monday-through-Sunday week for Sunday Planning while My Day remains in the ending week.
- The screen clearly names the week being planned without relying on color alone.
- If the target plan does not exist, the repository creates it by carrying forward the latest applicable ordered active Goals.
- Carry-forward is idempotent and never duplicates a plan or Goal.
- Prior-week snapshots remain unchanged.
- Empty, loading, ready, and recoverable failure states use calm language.
- Foreground, local-midnight, significant-time, and time-zone changes recapture the target week.

## Workflow

- Tier: 3.
- Rationale: Plan creation and carry-forward cross persistence, week boundaries, time zones, concurrency, and historical-data integrity.
