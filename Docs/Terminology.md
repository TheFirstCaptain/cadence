# Cadence Terminology

Use these terms consistently in product copy, code, tests, and documentation.

| Term | Meaning |
| --- | --- |
| Cadence | The product and the user's sustainable rhythm over time. |
| My Week | Primary area for the current plan, today's actions, and weekly progress. |
| Weekly plan | A flexible set of intentions for one calendar week. |
| Commitment | A wellness action the user intends to complete. |
| Checkoff | A completion record for a commitment on a particular day. |
| Sunday Planning | The lightweight flow for preparing the coming week. |
| iCheated | The quick, deliberately playful entry point for logging an indulgence. It must remain neutral and user-controlled. |
| Indulgence type | A custom category created by the user. |
| Indulgence entry | A timestamped record using an indulgence type. |
| History | A simple review of prior plans, checkoffs, and indulgence entries. |

Avoid `failure`, `broken streak`, `bad food`, `cheat score`, `compliance`, and other language that moralizes behavior.
