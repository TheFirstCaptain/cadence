# Cadence Terminology

Use these terms consistently in product copy, code, tests, and documentation.

| Term | Meaning |
| --- | --- |
| Cadence | The product and the user's sustainable rhythm over time. |
| My Day | Default destination showing today's Goals first and iCheated second. |
| My Goals | Working name for the area where the user creates and manages weekly Goals. |
| Weekly plan | A flexible set of Goals for one Monday-through-Sunday week. |
| Goal | A wellness action the user intends to complete. Goals are complete or incomplete for a particular day. |
| Checkoff | A completion record for a Goal on a particular day. |
| Daily frequency | Complete the Goal once each day of the Monday-through-Sunday week. |
| Weekly frequency | Complete the Goal once at any point during the week. |
| Custom frequency | Complete the Goal on a selected 2–6 days during the week, with at most one checkoff per day. |
| Sunday Planning | The My Goals flow for preparing the upcoming Monday-through-Sunday week while the current week is still ending. |
| iCheated | The quick, deliberately playful entry point for logging an indulgence. It must remain neutral and user-controlled. |
| Indulgence type | A custom category created by the user. |
| Indulgence occurrence | One timestamped iCheated event. One plus tap records one occurrence. |
| History | A simple review of prior plans, checkoffs, and indulgence occurrences. |

Avoid `failure`, `broken streak`, `bad food`, `cheat score`, `compliance`, and other language that moralizes behavior.
